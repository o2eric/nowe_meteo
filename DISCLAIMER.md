## Nieoficjalne (niepubliczne) API

Add-on korzysta z **nieudokumentowanego, wewnętrznego API** serwisu meteo.pl
(tego samego, którego używa aplikacja mobilna Meteo ICM). Takie API może:

- zostać w każdej chwili zmienione lub wyłączone,
- przestać działać bez ostrzeżenia,
- podlegać ograniczeniom regulaminu meteo.pl.

Korzystaj **odpowiedzialnie i z umiarem**: domyślny interwał odświeżania
(30 min) jest w zupełności wystarczający — nie obniżaj go agresywnie i nie
obciążaj serwerów źródła. Używaj **do celów osobistych/niekomercyjnych**.
